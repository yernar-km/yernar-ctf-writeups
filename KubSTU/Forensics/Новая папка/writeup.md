

Первым делом смотрим иерархию протоколов:

```bash
tshark -r Ratte.pcap -q -z io,phs
```

Видим HTTP, FTP, SSH, TLS, DNS — богатый набор. Но большинство из них — по одному пакету от случайных хостов. Классический **noise** для маскировки.

---

### Шаг 2 — Аномалия в соединениях

```bash
tshark -r Ratte.pcap -q -z conv,tcp
```

Выделяется одно соединение: `10.0.0.5:49152 → 10.0.0.15:**1337**` — 21 пакет, только исходящие. Порт 1337 — классический маркер backdoor/RAT (файл так и называется — *Ratte*, нем. "крыса").

---

### Шаг 3 — Разбор протокола

Извлекаем payload всех пакетов:

```bash
tshark -r Ratte.pcap -Y "tcp.port == 1337" -T fields -e tcp.payload
```

Получаем:
```
deadbeef42       ← Handshake (magic bytes)
cc53020937
ccb9022011
...
cc1e013f
```

Структура очевидна:
```
CC | seq(1B) | type(1B) | data(2B)
```

---

### Шаг 4 — XOR-брутфорс

Собираем все data-байты и перебираем однобайтовые XOR-ключи:

```python
for key in range(256):
    dec = bytes(b ^ key for b in all_bytes)
    if sum(32 <= b < 127 for b in dec) > len(all_bytes) * 0.7:
        print(f"key=0x{key:02x}: {dec.decode()}")
```

При `key = 0x42` получаем читаемый текст.
